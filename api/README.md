# Reference Harness API Deployment

This is demo deployment utility for Reference Harness in GCP using
@c6fc/spellcraft.

## Instructions

To deploy the application, start by opening a CloudShell console in your desired
GCP project. Then run the following commands:

```bash
git clone https://github.com/GoogleCloudPlatform/reference-harness.git
cd projects/reference-harness/api

npm install
cp settings.jsonnet.example settings.jsonnet
vim settings.jsonnet
```

Edit the settings file to set your desired region.

If you'd like to assess the configurations generated by spellcraft before
applying them, run:

```bash
 spellcraft generate manifest.jsonnet
```

This will render the configuration files into `render/`.

To deploy, run:

```bash
npx spellcraft terraform-apply manifest.jsonnet
```

Once deployment is complete, the script at ./rh-api.sh will create a curl
request to the deployed API, which will trigger a scan.
